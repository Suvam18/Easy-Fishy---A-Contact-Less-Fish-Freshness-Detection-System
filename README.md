🐟 Easy Fishy – AI-Based Contact -Less Fish Freshness Detection

🚀 Live Demo:
👉 https://easy-fishy-a-contact-less-fish-fres.vercel.app/

📌 Overview:
Easy Fishy is an AI-powered system that uses Computer Vision and Deep Learning to assess fish freshness in real time.
Instead of relying on subjective human judgment, the system classifies fish into multiple freshness levels with high accuracy.

This helps:

🛒 Vendors maintain quality standards

👨‍👩‍👧 Consumers make informed buying decisions

⚡ Reduce manual inspection errors

🎯 Features---
📸 Upload or capture fish images

🧠 AI-based freshness classification

⚡ Real-time prediction

📊 Multi-level freshness categorization

🌐 Clean and responsive web interface

🔍 Contactless freshness detection

🛠️ Tech Stack---
Frontend:
HTML
Tailwind CSS

Backend:
Python
Javascript 
TensorFlow / PyTorch (depending on your model)

Deployment:
Vercel (Frontend)

🧠 How It Works---
User uploads an image of fish 🐟

Image is preprocessed using OpenCV

Deep learning model analyzes features like:

Eye clarity 👁️

Texture 🧬

Color 🎨

Model predicts freshness level:

Fresh ✅

Medium ⚠️

Spoiled ❌

Result is displayed instantly
